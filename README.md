# Менеджер задач (Blazor Server, .NET 8)

Простое интерактивное приложение для управления задачами, реализованное на **Blazor Server** с использованием **.NET 10**.  
Поддерживает базовый **CRUD**: создание, отметку выполненных и удаление задач.

---

## 🎯 Цели проекта

- Научиться работать с **Blazor Server** и **компонентной архитектурой**.
- Реализовать **интерактивный CRUD** без сторонних библиотек.
- Понять работу с **EventCallback**, **@bind** и состоянием компонентов.
- Сделать простой, аккуратный интерфейс с адаптивной версткой.

---

## ⚙️ Технологии

- **.NET 8**
- **Blazor Server**
- C# 12
- HTML / CSS
- Visual Studio Code

---

## 🚀 Запуск проекта

Убедитесь, что установлен **.NET 8 SDK**:
dotnet --version
Перейдите в папку проекта:

cd BlazorTest
Запустите приложение с Hot Reload:

dotnet watch run
Откройте браузер:

http://localhost:5102
